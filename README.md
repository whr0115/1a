# 谭与相 - 爱情时光记录

这是一个浪漫的爱情时光记录页面，从2024年2月15日开始计算相伴天数。

## 功能特点
- 🎨 浪漫粉色渐变背景
- 💕 动态漂浮的爱心和玫瑰花装饰
- ⏰ 实时显示相伴天数、小时、分钟、秒数
- 📱 响应式设计，支持手机和电脑访问

## 本地运行
1. 下载 `index.html` 文件
2. 用浏览器直接打开即可运行

## 技术栈
- HTML5
- CSS3 (动画、渐变、媒体查询)
- JavaScript (时间计算、DOM操作)
